## 8004 Integration overview

The Praxis Explorer showcases ERC-8004 integration, providing:
- **Agent Identity Registry**: NFT-based agent registration and management
- **Reputation System**: On-chain feedback and rating collection
- **User Interface**: Interactive rating and agent discovery platform

## Smart Contract Integration

### Contracts Used

1. **IdentityRegistry**
   - ERC-721 NFT contract for agent registration
   - Each agent is represented as a unique NFT with metadata

2. **ReputationRegistry** 
   - ERC-8004 feedback collection contract
   - Stores ratings, reviews, and reputation data on-chain

### Key Functions Implementation

#### Agent Registration
```typescript
// Location: frontend/components/AddAgent.tsx
function register(tokenURI: string) -> uint256
```
- Mints new agent NFT to user's wallet
- Token URI points to agent metadata (IPFS or HTTP)
- Returns unique agent ID for reputation tracking

#### Feedback Submission
```typescript
// Location: frontend/hooks/useRating.ts
function giveFeedback(
  agentId: uint256,
  score: uint8,        // 10-100 scale (stars * 20)
  tag1: bytes32,       // Currently unused
  tag2: bytes32,       // Currently unused
  fileuri: string,     // Currently unused
  filehash: bytes32,   // Currently unused
  feedbackAuth: bytes  // 289-byte authentication data
)
```
- Submits rating for specific agent
- Score conversion: `Math.round(stars * 20)` (0.5-5.0 stars → 10-100)
- In the future would 289-byte feedbackAuth (224-byte struct + 65-byte signature)

#### Reputation Retrieval
```typescript
// Location: frontend/hooks/useAgentRating.ts
function getSummary(
  agentId: uint256,
  filters: bytes32[]   // Empty array for all feedback
) -> (uint8 averageScore, uint32 count)
```
- Gets aggregated rating data for an agent
- Returns average score (0-100) and total feedback count
- UI converts back to stars: `(averageScore / 100) * 5`

## Frontend Implementation

### Contract Interaction Hooks

#### useRating Hook (`frontend/hooks/useRating.ts`)
```typescript
const { submitRating, isPending, isConfirming, isConfirmed, error } = useRating()
```
- Handles rating submission to ReputationRegistry
- Creates 289-byte dummy feedbackAuth: `'0x' + '00'.repeat(289)`
- Uses wagmi's `useWriteContract` for transaction management

#### useAgentRating Hook (`frontend/hooks/useAgentRating.ts`)
```typescript
const { stars, count, isLoading } = useAgentRating(agentId)
```
- Fetches current rating from contract's `getSummary` function
- Converts contract score (0-100) to UI stars (0-5)
- Automatic refresh when ratings change


## Technical Details

### Authentication Workaround
The current implementation uses a 289-byte zero-filled `feedbackAuth`:
```typescript
const dummyAuth = '0x' + '00'.repeat(289)
```
This satisfies the contract's minimum length requirement (224-byte struct + 65-byte signature) without implementing full signature verification.

### Environment Configuration
Contract addresses are configurable via environment variables:
- `NEXT_PUBLIC_REGISTRY_ADDRESS`: IdentityRegistry contract
- `NEXT_PUBLIC_REPUTATION_REGISTRY_ADDRESS`: ReputationRegistry contract
